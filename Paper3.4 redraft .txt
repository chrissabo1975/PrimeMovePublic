Abstract
This paper presents a unified theory of hierarchical complexity emergence derived from the Prime Move Operator—a minimal five-stage cycle (Split → Tension → Failed Merge → Scar → Decay). We demonstrate that complexity organizes into a universal sequence of tiers: Linear → Hierarchical → Fractal → Wave → Dendritic → Perpetual, with each tier representing a distinct dimensional regime. Through geometric realization on expanding domains, we derive the emergence of the golden ratio φ ≈ 1.618 as an optimal packing constant and show that successive scars placed to minimize energy converge to the golden angle ≈ 137.5°. The dimensional progression (1D → 2D → fractal dimension → 3D oscillation → 3D networks → 4D time-binding) arises naturally from the operator’s recursive structure and provides a testable framework for understanding complexity across physical, biological, and social domains. Numerical experiments confirm φ-convergence within 0.01° by generation 50, validating the theory’s central predictions. We identify a critical branching point at Tier 3 (Fractal), where multiple generative pathways converge—detailed empirical validation of these pathways is provided in a companion paper.
Keywords: Prime Move Operator, hierarchical complexity, dimensional unfolding, golden ratio, geometric realization, scale invariance, Fibonacci sequence, emergence

3. Geometric Realization on Expanding Domains
3.1 Spatial State Space
To understand how the operator produces geometric patterns, we model scars embedded in an expanding circular domain.
Levels and Expansion.Let L ∈ ℕ index discrete “generations” or radial shells. Each level L has radius R_L > 0, with expansion rule:

R_{L+1} = R_L + \Delta R_L, \quad 0 < c_1 \le \Delta R_L \le c_2 < \infty

For canonical analysis, we consider:

R_L = \sqrt{L}

This corresponds to constant area allocation per scar—a condition arising naturally in botanical phyllotaxis (Vogel 1979, Douady & Couder 1996) and shown to produce optimal packing.
Angular Coordinates.The circle is represented as the quotient space 𝕋 := ℝ/2π ℤ. Each scar is a pair:

(L, \theta) \quad \text{with} \quad L \in \mathbb{N}, ; \theta \in \mathbb{T}

Configuration at Level L.The system state at step L is the finite set:

S_L = {(k, \theta_k) \mid 1 \le k \le L}

This represents the complete spatial history of all scars created through generation L.
3.2 Energy Functional and Packing Dynamics
Scar placement is governed by an energy functional encoding both spatial repulsion and temporal memory—the geometric manifestation of Tension (T) and Failed Merge (FM) stages.
Memory Kernel.Define a weight function:

w: \mathbb{N} \to [0,\infty), \quad \sum_{d=1}^\infty w(d) < \infty

The quantity w(L-k) represents the “memory strength” of a scar created L-k generations ago.
Canonical example (exponential decay):

w(d) = e^{-d/\lambda}

where λ > 0 is the memory length. For λ → ∞ (infinite memory), all previous scars contribute equally—this is the regime relevant for golden-angle emergence.
Repulsion Potential.Define a strictly decreasing function:

f: [0, \pi] \to \mathbb{R}

with f’(x) < 0, f(0) = +∞, f(π) finite.
This encodes spatial repulsion: scars repel more strongly when angularly close. Canonical choice:

f(x) = \frac{1}{x^2}

Angular Distance.On the circle:

\mathrm{dist}(\theta, \phi) = \min_{m \in \mathbb{Z}} |\theta - \phi + 2\pi m| \in [0, \pi]

Packing Energy.Given configuration S_L and candidate angle θ for the next scar:

E_L(\theta) = \sum_{(k, \theta_k) \in S_L} w(L - k) , f(\mathrm{dist}(\theta, \theta_k))

Interpretation:
	∙	Each existing scar contributes repulsion
	∙	Recent scars contribute more (via w(L-k))
	∙	Nearby scars repel more strongly (via f(dist))
This energy functional is the geometric realization of Tension and Failed Merge.
3.3 The Prime Move Update Rule
The operator on spatial state is defined by iterative energy minimization.
Initialization.Choose seed angle θ₁ ∈ 𝕋. Set S₁ = {(1, θ₁)}.
Inductive Step.Given S_L, the next scar angle is:

\theta_{L+1} \in \arg\min_{\theta \in \mathbb{T}} E_L(\theta)

Update state:

S_{L+1} = S_L \cup {(L+1, \theta_{L+1})}

This defines the discrete-time operator:

\mathcal{P}: S_L \mapsto S_{L+1}

We call this the Prime Move operator on scars over expanding geometry.
3.4 Well-Posedness
Proposition 3.1 (Existence and Uniqueness of Minimizers).For any memory kernel w satisfying ∑w(d) < ∞ and any strictly decreasing repulsion function f with f(0) = +∞, the energy functional E_L(θ) admits a unique global minimum on 𝕋 for each L ∈ ℕ.
Proof Sketch:
	1.	𝕋 is compact
	2.	E_L is continuous (finite sum of continuous functions)
	3.	E_L(θ) → +∞ as θ approaches any existing scar (coercivity)
	4.	By Weierstrass Theorem, minimum exists
	5.	Strict convexity of f (e.g., f’’ > 0 for f(x) = 1/x²) ensures uniqueness □
The operator is thus mathematically well-defined at each step.
3.5 Divergence Angle and Asymptotic Dynamics
Divergence Increments.Define the angle increment between consecutive scars:

\Delta\theta_L = \theta_L - \theta_{L-1} \pmod{2\pi}, \quad L \ge 2

Rotation Number.The asymptotic rotation number (when the limit exists):

\rho = \lim_{L \to \infty} \frac{\theta_L}{2\pi L}

The limiting divergence angle is:

\alpha = 2\pi \rho = \lim_{L \to \infty} \Delta\theta_L

This is the characteristic angular spacing between successive scars.

4.3 The Branching Point at Tier 3
A critical architectural feature of the ladder is that Tier 3 (Fractal) admits multiple convergent pathways. Unlike Tiers 1-2, which have a single route, and Tiers 4-6, which build uniquely on Tier 3, the fractal tier can be reached via at least three distinct mechanisms:
Pathway A: Spiral
	∙	Mechanism: Asymmetric tension + directional memory
	∙	Signature: φ ≈ 1.618 in angles and ratios; golden angle ≈ 137.5°
	∙	Geometric form: Logarithmic or Archimedean spirals
	∙	Examples: Nautilus shell, spiral galaxies, hurricane bands
Pathway B: Optimization
	∙	Mechanism: Symmetric constraints + efficiency pressure
	∙	Signature: Murray’s law (r³ exponent ≈ 3); hexagonal packing (120°)
	∙	Geometric form: Optimized branching or packing structures
	∙	Examples: Circulatory system, honeycomb, crystal lattices
Pathway C: Aggregation
	∙	Mechanism: Diffusion-limited random walks + sticking
	∙	Signature: DLA fractal dimension D ≈ 1.7 (2D); power-law distributions
	∙	Geometric form: Cluster fractals with random branching
	∙	Examples: Coastlines, lightning, snowflakes
Why Branching Occurs:The Prime Move operator runs identically in all three cases—five stages, same recursion, same Fibonacci accumulation. What differs are the tuning parameters:



|**Parameter**        |**Spiral**|**Optimization**|**Aggregation** |
|---------------------|----------|----------------|----------------|

|Memory persistence   |Long      |Short           |Not required    |

These tuning parameters emerge from local conditions (physical constraints, environmental pressures, initial conditions). The operator does not “choose” a pathway—the pathway is determined by the system’s context.
Convergence on Fractal:Despite different routes, all three pathways produce genuine fractal scaling:
	∙	Spiral: Self-similarity from recursive angle addition
	∙	Optimization: Self-similarity from iterated efficiency
	∙	Aggregation: Self-similarity from stochastic branching
